วิธีเชื่อมต่อ LINE Official Account

LINE INTEGRATION

ตั้งค่า LINE OA ให้หอของคุณ

แต่ละหอต้องมี LINE Official Account เป็นของตัวเอง เพื่อไม่ให้เลขห้องชนกับหอข้างเคียงตอนผู้เช่าลงทะเบียน

ทำใน LINE Developers Console ทำในเว็บนี้

ทำไมต้องทำแบบนี้

บอทตัวเดียวใช้ร่วมกันไม่ได้

ถ้าทุกหอใช้ LINE บอทตัวเดียวกัน ตอนผู้เช่าลงทะเบียนด้วยการพิมพ์เลขห้อง ระบบจะแยกไม่ออกว่า "ห้อง 101" ที่พิมพ์มาเป็นของหอไหน เพราะหลายหอมักมีเลขห้องซ้ำกัน — แยกบอทต่อหอ ปัญหานี้หมดไปทันที

ส่วนที่ 1 · ~10 นาที · ไม่มีค่าใช้จ่าย

สร้าง LINE Official Account

  1. LINE Developers Console

    เข้า developers.line.biz แล้วเข้าสู่ระบบ

    ใช้บัญชี LINE ปกติ หรือสร้าง LINE Business ID ก็ได้

  2. LINE Developers Console

    สร้างผู้ให้บริการ (Provider)

    ถ้ายังไม่เคยมี กด Create แล้วตั้งชื่ออะไรก็ได้ เช่น ชื่อหอ หรือชื่อธุรกิจ

  3. LINE Developers Console

    สร้างช่องทาง (channel) แบบ Messaging API

    ในหน้า Provider กด Create a channel → เลือก Messaging API → กรอกชื่อ OA รูปโปรไฟล์ หมวดหมู่ แล้วกด Create จนเสร็จ

  4. LINE Developers Console

    คัดลอก Channel Access Token

    เข้า channel ที่สร้าง → แท็บ Messaging API → เลื่อนหาหัวข้อ Channel access token → ถ้ายังไม่มีกด Issue → กดคัดลอกเก็บไว้

    เก็บให้ดี ห้ามแชร์ต่อ — เหมือนรหัสผ่านของบอท

ส่วนที่ 2 · ~3 นาที

เชื่อมเข้าระบบของเรา

  1. เว็บนี้

    เปิดหน้า "โปรไฟล์ของฉัน" → หัวข้อ "หอของฉัน"

    วาง Channel Access Token ในช่องที่เตรียมไว้ แล้วกดบันทึกข้อมูลหอ

    ระบบจะเช็คกับ LINE ทันทีตอนกดบันทึก — ถ้า token ผิดจะแจ้งเตือนเลย ไม่ต้องรอไปเจอตอนส่งบิลจริง

  2. LINE Developers Console

    ตั้งค่า Webhook URL

    กลับไปแท็บ Messaging API เดิม เลื่อนหา Webhook settings → กด Edit → วาง URL ด้านล่างนี้ → กด Update → เปิดสวิตช์ Use webhook ให้ติด

  3. LINE Developers Console

    ปิด auto-reply เริ่มต้นของ LINE

    ไปที่แท็บ LINE Official Account features → เปิดลิงก์ไป LINE Official Account Manager → ปิด Greeting message และ Auto-reply messages ไม่งั้นจะชนกับข้อความที่ระบบเราตอบเอง

💡

ปุ่ม "Verify" ข้าง Webhook URL อาจขึ้น timeout — ปกติของระบบที่ใช้ Google Apps Script เป็น backend เพราะตอบช้ากว่าที่ปุ่มนี้จะรอไหว ไม่ได้แปลว่าเชื่อมต่อไม่ได้จริง วิธีที่ชัวร์สุดคือลองแอดเพื่อนแล้วพิมพ์เลขห้องดูตามส่วนที่ 3 ด้านล่าง

ส่วนที่ 3

ผู้เช่าลงทะเบียนยังไง

ส่ง QR code ของ OA ให้ผู้เช่าสแกนแอดเป็นเพื่อน แล้วให้ทำตามนี้

สวัสดีครับ 🙏 ยินดีต้อนรับสู่ระบบแจ้งบิลหอพักสบายดี กรุณาพิมพ์ "เลขห้อง" ของคุณ (เช่น 101) เพื่อลงทะเบียนรับใบแจ้งหนี้ทาง LINE
101
ลงทะเบียนสำเร็จ ✅ คุณ สมชาย ใจดี ห้อง 101 ระบบจะส่งใบแจ้งหนี้ให้ทาง LINE นี้ครับ

ส่วนที่ 4

ใช้งานประจำวัน — ส่งบิลจนถึงยืนยันจ่ายเงิน

กด "ส่ง LINE" บนบิลที่หน้าเว็บของเรา ที่เหลือทำงานผ่านแชทเป็นหลัก

กด "ส่ง LINE" → ผู้เช่าได้บิล + QR → สแกนจ่าย → ส่งสลิปในแชท → เจ้าของหอกดยืนยัน
ได้รับสลิปแล้วครับ ⏳ รอเจ้าของหอตรวจสอบและยืนยันการชำระเงินครับ
ยืนยันการชำระเงินเรียบร้อยแล้วครับ ✅ ขอบคุณครับ
📋

ข้อความ "ยืนยันการชำระเงิน" จะส่งออกไป ก็ต่อเมื่อ เจ้าของหอกดปุ่ม "ยืนยันชำระแล้ว" ที่บิลใบนั้น — ระบบไม่ยืนยันเงินให้อัตโนมัติ ต้องมีคนเช็คสลิปก่อนเสมอ เพื่อกันสลิปปลอม

คำถามที่พบบ่อย

ติดขัดตรงไหน เช็คตรงนี้ก่อน

ต้องทำกี่ครั้ง

ทำครั้งเดียวต่อหอ 1 หอ ต่อ LINE OA 1 บัญชี ไม่ต้องทำซ้ำอีก

เปลี่ยน token ทีหลังได้ไหม

ได้ กลับมาวาง token ใหม่ที่หน้าโปรไฟล์แล้วบันทึกอีกครั้ง ถ้าปล่อยช่องว่างไว้แล้วบันทึก ระบบจะคงค่าเดิมไว้ ไม่ได้ตัดการเชื่อมต่อ

ไม่เห็นปุ่ม "QR พร้อมเพย์" บนบิล

ต้องตั้งค่าเลขพร้อมเพย์ในหน้าโปรไฟล์ก่อน (แยกจาก LINE token คนละช่องกัน) ปุ่มถึงจะขึ้น
