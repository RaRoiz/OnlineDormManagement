# สิทธิ์สลิป

สลิปใหม่เก็บเป็นไฟล์ส่วนตัว หน้าเว็บใช้ `getBillSlip` พร้อม token และ billId
backend ตรวจบัญชี Users ว่ายัง active และเป็น OWNER / SUPER_ADMIN / USER
แล้วส่งรูปกลับมา ไม่มี Drive URL ใน API รายการบิล และไม่ cache เนื้อหารูป

## นำขึ้นใช้งาน

1. Push backend จากโฟลเดอร์ `backend` ด้วย `clasp.cmd push` แล้ว deploy Web App เป็นเวอร์ชันใหม่
   ต้องมีทั้ง `Slips.js` และ `Line.js` (ไฟล์ Line.js ของโปรเจกต์นี้ถูก Git ignore แต่ clasp ติดตามอยู่)
2. Build และ deploy frontend พร้อมกัน เพราะปุ่มดูสลิปใช้ API ใหม่
3. ใน Apps Script editor รัน `previewSlipPrivacyMigration` เพื่อดูรายการที่จะเปลี่ยน
4. รัน `restrictExistingPaymentSlips` เพื่อปิดการแชร์ด้วยลิงก์ของสลิปที่อ้างอิงในชีต PaymentSlips
   ตรวจผลลัพธ์แต่ละรายการ ต้องไม่มี `failed`; แก้สิทธิ์ต้นทางแล้วรันซ้ำได้
5. ทดสอบดูสลิปจากบัญชีทั้งสามบทบาท และลองเปิดลิงก์ Drive เดิมจากเบราว์เซอร์ที่ไม่ได้ล็อกอิน Google

ต้องใช้โฟลเดอร์สลิปส่วนตัวของบัญชีที่ deploy ไม่มีการแชร์โฟลเดอร์แม่หรือแชร์รายบุคคล
หากโฟลเดอร์เดิมแชร์ร่วมกับงานอื่น ให้สร้างโฟลเดอร์ส่วนตัวแล้วตั้ง `SLIP_FOLDER_ID`
โค้ดจะไม่เปลี่ยนสิทธิ์โฟลเดอร์แม่หรือถอนสิทธิ์บุคคลอื่นอัตโนมัติ
การตรวจด้วย DriveApp ไม่ใช่การตรวจสิทธิ์ Shared Drive/Google Groups แบบครบถ้วน
จึงควรใช้โฟลเดอร์ส่วนตัวใน My Drive สำหรับรูปแบบการเข้าถึงนี้

การ migration ครอบคลุมเฉพาะไฟล์ที่ยังมีลิงก์ใน PaymentSlips
สลิปเก่าที่ถูกแทนที่จนไม่มีลิงก์ในชีตต้องตรวจแยกใน Drive
สิทธิ์เดิมยังมีผลจนกว่าจะรัน migration สำเร็จ
เจ้าของไฟล์และผู้ที่ยังได้รับสิทธิ์ใน Drive โดยตรงยังเข้าถึงได้ตามสิทธิ์ Google

## ตรวจในเครื่อง

จาก root โปรเจกต์: `node --test tests/slips.test.cjs`

## ตรวจสอบและปฏิเสธสลิป

ปุ่มตรวจสอบสลิปแสดงรูปและยอดล่าสุด พร้อมยืนยันหรือปฏิเสธ (ต้องระบุเหตุผล)
ระบบเก็บประวัติพร้อมผู้ตรวจในชีต `SlipReviews` ซึ่งสร้างอัตโนมัติ
ผลยืนยันเปลี่ยนบิลเป็น PAID; ผลปฏิเสธเปลี่ยนเป็น UNPAID และแจ้ง LINE
ถ้า LINE ส่งไม่สำเร็จ หน้าเว็บแจ้งเตือนให้ติดต่อผู้เช่าเองโดยไม่ย้อนผลตรวจ

เมื่อมีบิล PENDING ระบบไม่รับรูปเพิ่มไปผูกบิลค้างใบอื่นโดยอัตโนมัติ
หลังปฏิเสธ สลิปใหม่จะกลับเข้าบิลเดิม แม้มีบิลค้างที่เก่ากว่า
ถ้ามีหลายบิลถูกปฏิเสธพร้อมกัน ระบบขอให้ติดต่อเจ้าของหอแทนการเดาบิล
ประวัติรูปและผลตรวจใหม่เก็บไว้ใน SlipReviews ส่วน PaymentSlips เก็บลิงก์ล่าสุด

ต้อง push `SlipReview.js`, `Slips.js`, `Line.js`, `Bill.js`, `Code.js` และ deploy
backend เวอร์ชันใหม่ พร้อม frontend เพื่อให้ปุ่มตรวจสอบและ API ตรงกัน
การเปลี่ยนนี้ไม่ตรวจสลิปกับธนาคารอัตโนมัติ ผู้ตรวจยังเป็นผู้ยืนยันการชำระเงินจริง

ทดสอบเพิ่มเติม: `node --test tests/slip-review.test.cjs tests/slip-dialog.test.cjs`
